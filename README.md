# W-Note

W-Note è un'app mobile sviluppata con React Native/Expo pensata per la gestione degli allenamenti in palestra.

L'app permette all'utente di creare e visualizzare schede di allenamento, gestire gli esercizi, avviare una sessione di workout, registrare le serie completate con carico, ripetizioni e note, utilizzare un timer di recupero tra le serie e consultare lo storico degli allenamenti svolti.

## Funzionalità principali

* Creazione e gestione delle schede di allenamento
* Aggiunta, modifica ed eliminazione degli esercizi
* Avvio e conclusione di una sessione di allenamento
* Registrazione di serie, ripetizioni e carichi in kg
* Timer di recupero tra le serie
* Pausa dell'allenamento
* Salvataggio dei dati in locale
* Visualizzazione dello storico degli allenamenti

## Obiettivo del progetto

L'obiettivo di W-Note è offrire uno strumento semplice e intuitivo per organizzare gli allenamenti, tracciare i progressi e gestire in modo ordinato le proprie sessioni in palestra.
